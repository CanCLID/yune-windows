# M05 Evidence

M05 evidence is retained as compact summaries:

- `summary.md`
- `summary.json`

The retained evidence separates executed proof, source contracts,
post-reboot holder-free live proof, follow-up coverage, and deferred work.

Executed proof covers non-elevated build, scratch server, and dev REPL
verification for server-owned IME state, `op=` verbs, ascii pass-through crash
hardening, persisted ascii restart, invalid request survival, and
settings/schema-cycle fallback. Source contracts cover TSF hotkeys,
mid-composition toggle cleanup, lone-Shift guards, non-launching focus refresh,
the focus-scoped native language bar, and `YuneWindowsSettings.exe`.

Holder-free live proof covers the post-reboot installed server reload,
installed TSF DLL swap, profile activation, settings executable installation,
and manual dev Notepad verification for the M05 typing controls. Chromium,
native Windows input-mode indicator observation, and broader host coverage are
follow-up compatibility evidence, not M05 closeout blockers.
